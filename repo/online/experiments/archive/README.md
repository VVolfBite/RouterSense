# Archive Experiments

This directory is reserved for historical experiment runners that are no longer
part of the official public workflow.

Current public entrypoints:

- `experiments/run_offline_replay.py`
- `experiments/run_online_phase_sync.py`
- `experiments/run_online_async_release.py`
- `experiments/dev/run_validation.py`
- `experiments/reporting/build_report.py`

Current internal validation implementations remain under `experiments/distributed/`
and `experiments/online/` until they are fully migrated or retired.
